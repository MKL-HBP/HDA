# 하버브릭스 AI 투자분석

기업명과 PDF를 선택하고 가상 기업의 투자 검토 보고서를 열어보는 **로컬 샘플 앱**입니다.

## 실행

앱 실행은 Node.js 20.9 이상, 테스트 실행은 Node.js 22.18 이상을 사용합니다. 패키지 관리자는 pnpm입니다.

```sh
pnpm install
pnpm dev
```

주소: http://127.0.0.1:3000 (기본 포트)

```sh
pnpm typecheck
pnpm test
pnpm build
```

## 사용 방법

1. 기업명을 입력합니다.
2. PDF 파일 하나를 선택하거나 끌어다 놓습니다. 최대 20MB입니다.
3. **분석 시작**을 누르면 약 2초 후 샘플 보고서가 열립니다.
4. **샘플 보고서 먼저 보기**로 파일 없이도 보고서를 볼 수 있습니다.
5. **새 분석**으로 화면을 초기화합니다.

## 샘플 모드의 범위

- PDF의 확장자·크기·앞 5바이트 형식 표시만 확인합니다. PDF 본문 추출과 AI 분석은 하지 않습니다.
- 선택한 파일은 외부 서버에 전송하거나 저장하지 않습니다. 기업명·파일명은 현재 브라우저 메모리에만 보관합니다.
- 입력한 기업명이나 PDF 내용과 무관하게 **블루포트 테크놀로지**라는 가상 기업의 고정 보고서가 표시됩니다.
- 기업, 제품, 경쟁사, 재무정보, 투자 포인트 등은 모두 가상 데이터입니다. 실시간 산업·뉴스 검색은 수행하지 않습니다.
- 성장률·영업이익률은 가상 원천 수치에서 계산합니다. 보고서에서 계산식을 확인할 수 있습니다.
- 기업가치는 산출하지 않으며 **미산정**으로 표시합니다.
- 파일·보고서·체크리스트는 영구 저장되지 않습니다. 새로고침하면 처음 화면으로 돌아갑니다.
- 외부 폰트, 이미지, 분석 추적 스크립트 또는 API가 필요하지 않습니다.

## 구성

- `src/app/page.tsx`: 업로드, 진행 상태, 보고서, 안내 창
- `src/app/globals.css`: 데스크톱·태블릿·모바일 레이아웃
- `src/lib/report.ts`: 보고서 타입, 가상 데이터, 샘플 제공자, PDF 형식 확인
- `src/app/layout.tsx`: 한국어 페이지 정보

Next.js App Router와 TypeScript를 사용합니다. 패키지 버전은 `pnpm-lock.yaml`으로 고정합니다.

## 다음 단계 연결 계획

현재는 아래 서비스에 연결하는 코드나 키가 없습니다. 연결 시 샘플·실제 데이터의 출처를 명확히 구분해야 합니다.

| 기능 | 서비스 | 연결 시 필요한 작업 |
| --- | --- | --- |
| PDF 분석 | Gemini | 서버 전용 API 경로, 파일 검증, 구조화된 결과 검증, 페이지별 근거 |
| 파일·결과 저장 | Supabase | 인증, 비공개 파일 저장소, 사용자별 접근 정책, 보존·삭제 정책 |
| 재무정보 조회 | Open DART | 기업 고유번호 매칭, 연결/별도 재무 구분, 기간·단위·공시 출처 기록 |
| 산업·경쟁사·뉴스 | Tavily | 검색일, 발행일, 원문 링크, 사실·추정 구분 |
| 기업가치 평가 | 검증 가능한 계산 모듈 | 원천 수치·단위·가정 검증, DCF/배수 계산, 민감도, 테스트 |

키는 서버 환경변수로만 관리합니다. 실제 분석 제공자는 파일·출처·오류·진행 상태에 대한 별도 계약을 추가하고, 샘플 제공자를 그대로 유지하는 방식으로 확장할 수 있습니다.
